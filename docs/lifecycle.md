# 安装、连接与移除

当前是需要配套 Orca 宿主的开发预览。公开 Orca 的兼容性和目录收录状态见[发布指南](releasing.md)。本页区分正式安装、开发挂载、账号连接和各自的数据清理范围。

## 正式安装

在兼容的 Orca 中打开「设置 → 插件」，使用 Git 仓库安装入口选择 `jiang3ye/orca-plugin-meego` 的已验证版本。检查来源、插件身份 `jiang3ye.meego` 和请求的权限后再批准。安装完成后，可在「设置 → 集成」进入飞书项目连接页。

CLI 也使用 Orca 自带的安装器：

```sh
orca plugin install jiang3ye/orca-plugin-meego@<已验证版本标签> --json
```

这里的版本占位符需要替换成实际可用的版本；未满足宿主兼容门槛的开发草稿不是可安装的目录版本。第一次执行会要求批准，按返回的命令使用本次准确的权限指纹继续，不要复制其他版本的指纹。无需 npm 发布或安装同名 npm 包。

开发验收使用经源码清单审阅的干净源码快照安装，不能将包含 `.orca/`、依赖、凭据或验收记录的整个开发目录当作安装源。

## 连接管理

侧栏的「集成设置」可进入连接页；连接页提供以下不同操作：

| 操作 | 本机效果 | 保留范围 |
| --- | --- | --- |
| 断开连接 | 停止当前连接和授权等待，断开后不再用原连接发起业务请求 | 账号/空间偏好、高级配置与工作区关联；企业凭据只能经显式连接恢复使用 |
| 移除连接 | 确认后删除个人授权凭据、企业凭据、账号/空间选择，并恢复高级连接的默认值 | 已有工作区关联及创建结果记录；不删除远端工作项或本地工作区，不关闭 Agent |

断开或移除是本机连接管理，不代表已在飞书服务端撤销应用授权，也不会退出其他客户端上的飞书账号。移除未完成时应显示失败并允许重试，不能将残留凭据自动当成可用连接。

## 禁用与卸载

连接页的「管理插件」进入 Orca 插件管理。

- 暂时停用时选择禁用；插件停止运行，数据保留。
- 正式安装版选择「移除」，确认后由 Orca 停止插件、删除安装文件、插件自身的本地设置/存储/加密凭据并撤销其本机批准。Orca 的宿主审计记录不属于插件数据，可能保留。
- 重新安装需要重新检查并批准权限，再连接飞书账号。

CLI 的卸载入口为：

```sh
orca plugin uninstall jiang3ye.meego --json
```

本地路径安装的身份通常为 `local.meego`；以实际插件列表显示的身份为准，不能把本地开发版的凭据路径当成正式 Git 安装版的路径。

## 移除开发挂载

开发挂载的插件卡片/详情提供「移除开发挂载」。它停止加载该目录，保留源码、插件数据和开发批准；它不等于正式安装版的卸载。也可在「设置 → 插件 → ⋯ → 开发目录」管理挂载。

```sh
orca plugin dev unload /绝对路径/orca-plugin-meego --json
```

开发挂载不会自动变成正式安装。正式使用前应移除开发挂载，再安装经验证的发布版本。

## 验证范围

生命周期验收应使用独立临时用户目录和干净的真实 Meego 源码，覆盖首次批准、安装、禁用/启用、升级产生的回退副本、卸载清理、重新安装和开发挂载移除。测试只写入合成凭据与数据，不访问真实飞书业务，也不操作当前用户的 Orca 配置。

Native installer/service 集成测试、组件渲染和完整 Electron 交互验收是不同层次；报告通过时应明确实际执行的层次和证据。
